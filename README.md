A modern, high-performance **Developer Portfolio Website** engineered with **React 19, TypeScript 5.7, Tailwind CSS, Vite 6, and Framer Motion**. Showcases 12 production-grade repositories spanning **Data Analytics, Machine Learning models, Autonomous AI Agents (Google Gemini 3.8 Flash), Full-Stack Systems, and 245+ solved LeetCode challenges** alongside verified credentials, interactive modals, and recruiter-friendly action hubs.

🌐 **Live Deployments**:
- **Primary (Vercel)**: [https://portfolio-preyal2s-projects.vercel.app](https://portfolio-preyal2s-projects.vercel.app)
- **Mirror (Netlify)**: [https://preyal1portfolio.netlify.app/](https://preyal1portfolio.netlify.app/)

## 🌟 Key Highlights & Architectural Features

- ⚡ **Glassmorphic Obsidian Aesthetic**: Sleek Dark palette (`#0A0A0A`, `#2563EB`, `#7C3AED`, `#38BDF8`) with dynamic glowing neon accents and responsive interactive UI.
- 🎯 **Recruiter Action Hub**: Dedicated "Hire Me" modal and Recruiter Action Banner with instant PDF resume downloads, 1-click email scheduling, and direct avenue connections.
- 📁 **Interactive 12-Project Showcase**: 6 dynamic category filters (*All, AI & Agents, Machine Learning, Data Analytics, Web & Systems, DSA & Practice*) with collapsible architectural deep dives, key features, challenges, and direct live links.
- 📊 **Real-Time GitHub & LeetCode APIs**: Live integration fetching public repositories, contribution heatmaps, problem-solving telemetry, and global ranking stats.
- 📜 **Certificate & Achievement Viewer**: Interactive credential modal with full-screen verification, credential IDs, issuing authority badges, and direct PDF downloads.
- 📱 **100% Fully Responsive**: Fluid layouts engineered for desktop, tablet, and mobile with smooth touch gestures and performant spring physics via Framer Motion.

## 💻 Local Development Setup

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / pnpm / yarn

### Installation Steps

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/preyal2/portfolio.git
   cd portfolio
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173/`

4. **Build for Production**:
   ```bash
   npm run build
   ```
